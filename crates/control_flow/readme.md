# Control Flow

This is a customized version of the Control Flow exercises, developed in [Chapter 3](https://doc.rust-lang.org/book/ch03-05-control-flow.html) of [The Rust Programming Language](https://doc.rust-lang.org/stable/book) book, for Rust version `1.78.0`.

## Installation

Clone this repository:

```sh
git clone https://github.com/herberthleao/rust-book-exercises.git
```

Go to this crate's directory:

```sh
cd rust-book-exercises/crates/control_flow
```

Run the program:

```sh
cargo run
```

## Usage

In the program menu, you can choose between three cases:
1. Convert temperatures between Fahrenheit and Celsius
2. Generate the nth Fibonacci number
3. Print the lyrics to the Christmas carol “The Twelve Days of Christmas”
